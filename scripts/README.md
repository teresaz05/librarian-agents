# Scripts

- `reproduce_results.sh` recomputes metrics from the bundled compact records.
- `prepare_browsecomp_plus.sh` and `prepare_bright_qa.sh` prepare benchmark data.
- `train_browsecomp_plus.sh` runs paper-configured training.
- `build_bright_filesystems.sh` and `build_browsecomp_filesystems.sh` construct memories.
- `evaluate_bright_qa.sh`, `evaluate_browsecomp_plus.sh`, and
  `evaluate_hierarchy_ablation.sh` run the paper evaluations.
- `run_bright_baselines.sh` generates the matched BRIGHT baselines.
- `check_release.sh` runs repository checks and tests.
