# Inference

Filesystem answering and matched retrieval baselines for BrowseComp+ and BRIGHT.

- `answer.py` answers queries from constructed filesystems.
- `bright_frozen_filesystem.py` evaluates question-blind BRIGHT filesystems.
- `browsecomp_hierarchy_ablation.py` evaluates the hierarchy transformations.
- `strong_retrieval.py`, `retrieve.py`, and `retrieve_colbert.py` implement retrieval baselines.
- `graph_rag.py`, `agentic_rag.py`, and `autocompaction_rag.py` implement structured baselines.
